# 🚀 Your 1-Day Project: Mini Google Forms

**Bottom Line:** We are building a simple questionnaire builder to show off at your Diligent interview! You will build it today, step-by-step.

---

## 🛠️ The Tech Stack (Keep it simple!)

We are using the easiest, fastest setup so you don't get stuck on setup errors.

| Part | Tech | Why it's the best choice for today |
| :--- | :--- | :--- |
| **Frontend** | React (Vite) + MUI | Fast to start. MUI gives us beautiful buttons instantly. |
| **Backend** | ASP.NET Core (Minimal APIs) | Very little code! Looks just like Node.js. |
| **Database** | SQLite + EF Core | No server to install. It just creates a local file. |

---

## 🧗‍♀️ Your Step-by-Step Action Plan

We will build the app in the most logical order: **Builder -> Viewer -> Dashboard**. We will do this one small chunk at a time. No overwhelm!

### Phase 1: Project Setup
*   Generate the .NET API and check if it runs.
*   Add the SQLite database connection.
*   Generate the React app and install MUI.

### Phase 2: The Builder Page (Start Here! 🏗️)
*   **Backend:** Create a POST endpoint to save a new questionnaire.
*   **Frontend:** Build the UI to add Questions (Text & Checkbox) and a "Save" button.

### Phase 3: The Viewer Page (Check your work 👀)
*   **Backend:** Create a GET endpoint to fetch a single questionnaire by ID.
*   **Frontend:** Build the UI to render the saved questionnaire as a read-only form.

### Phase 4: The Dashboard Page (The Finale 📋)
*   **Backend:** Create a GET endpoint to fetch a list of all saved questionnaires.
*   **Frontend:** Build a table/list UI to display them and link to the Builder/Viewer.

> [!IMPORTANT]
> Does this bite-sized plan look good? Whenever you are ready to code, just say the word and we will start with Phase 1!
