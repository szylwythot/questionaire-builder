# 🎯 Mini Google Forms (Training Project)

Welcome! This is a **training and portfolio project** built to demonstrate full-stack development skills using modern .NET and React.

## 💡 What is it?
This project is an MVP (Minimum Viable Product) for a dynamic questionnaire builder—similar to a simplified Google Forms. It allows users to:
1.  **Build** a custom questionnaire with text and multiple-choice (checkbox) questions.
2.  **View** the finalized read-only form exactly as a user would see it.
3.  **Manage** a list of all created questionnaires in a central dashboard.

## 🛠️ The Tech Stack
This project focuses on simplicity, modern tooling, and clean architecture:
*   **Frontend:** React (scaffolded with Vite) for a fast development experience.
*   **UI Library:** Material UI (MUI) for clean, accessible, and responsive components.
*   **Backend:** ASP.NET Core 8 using **Minimal APIs** for lightweight, high-performance endpoints.
*   **Database:** SQLite + Entity Framework (EF) Core for simple, file-based data storage without complex server setups.
