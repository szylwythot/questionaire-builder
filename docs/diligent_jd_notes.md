## 📌 Full Job Description (For AI Context)

**Role:** Fullstack Software Engineer (.Net and React)

Tired of just writing boilerplate? Ready to orchestrate, refine, and ship high-impact product features with modern agentic workflows?

If you are a builder who pairs solid engineering fundamentals with cutting-edge AI dev tools to multiply your impact, you’ll fit right in. You won’t just prompt and hope - you know how to critically review, debug, and architect resilient code that actually scales.

**Here’s a breakdown of what you’ll do (not all of it, just the important stuff):**
*   **Drive product features end-to-end:** Implement sleek, responsive UI improvements and connect them seamlessly with underlying APIs and backend services.
*   **Supercharge your workflow:** Leverage agentic coding assistants and AI workflows to accelerate delivery, prototype fast, and automate repetitive engineering tasks.
*   **Be the human in the loop:** Critically challenge, review, and refactor AI-generated code to maintain high architectural standards, security, and test coverage.
*   **Collaborate in cross-functional squads:** Partner closely with product designers, managers, and peer engineers in an agile cadence to turn ideas into production-ready software.
*   **Level up code quality:** Participate in code reviews, optimize client-side performance, and champion maintainable, clean-code practices across the codebase.

**These are the essentials you’ll need to get an interview:**
*   **Solid frontend foundations:** Proven professional experience building modern, responsive web applications using modern JavaScript/TypeScript and component-based frameworks (like React, Angular, or Vue).
*   **Full-stack awareness:** Comfortable navigating backend services, RESTful APIs, and basic data models to ship complete features independently.
*   **Hands-on agentic development:** Demonstrated experience actively utilizing AI dev tools (e.g., Cursor, Claude Code, GitHub Copilot, Windsurf) in your daily development lifecycle.
*   **Strong code scrutiny & debugging:** Exceptional ability to audit, debug, and refactor generated code for edge cases, performance bottlenecks, and architectural coherence.
*   **Pragmatic problem solver:** A curious, product-first mindset with strong communication skills and an eagerness to learn and collaborate with a Budapest-based team.

**It would be great if you had these too, but we’ll support you if you don’t:**
*   Experience with automated testing suites (unit, integration, and E2E like Jest, Playwright, or Cypress).
*   Familiarity with containerized development environments (Docker) and CI/CD deployment pipelines.
*   Hands-on experience building custom agentic workflows, prompt chaining, or LLM-driven tooling.
*   Exposure to cloud-native platforms (AWS, Azure) or distributed systems.
